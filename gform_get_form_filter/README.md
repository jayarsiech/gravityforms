# مدیریت دسترسی و زمان‌بندی جشنواره پس از پرداخت (Gravity Forms Payment Success Actions)

این قطعه کد (Snippet) برای وب‌سایت‌های وردپرسی طراحی شده است که از افزونه **Gravity Forms** برای ثبت‌نام یا فروش ورودی‌های جشنواره استفاده می‌کنند. این کد با بررسی وضعیت پرداخت کاربر در یک فرم خاص، به‌طور خودکار دسترسی‌های لازم را در پروفایل کاربر فعال کرده و بازه‌های زمانی بررسی (۳، ۶، ۱۵ و ۳۰ روزه) را محاسبه و ذخیره می‌کند.

## 🚀 ویژگی‌های کلیدی (Features)
* **بررسی وضعیت پرداخت:** شناسایی ورودی‌های با وضعیت `Paid` برای کاربر لاگین شده.
* **تغییر ظاهر فرم:** جایگزینی خودکار فرم با پیام موفقیت و دکمه ورود به پنل در صورت پرداخت قبلی.
* **زمان‌بندی خودکار:** محاسبه و ذخیره تاریخ‌های سررسید (۳ تا ۳۰ روزه) از لحظه تایید پرداخت در متادیتای کاربر.
* **اتوماسیون پروفایل:** به‌روزرسانی فیلدهای `moghadamati` و `jashnvare8+` بلافاصله پس از تایید تراکنش.

## 🛠 نحوه استفاده (Installation)
۱. ابتدا کد موجود در فایل مربوطه را کپی کنید.
۲. آن را به انتهای فایل `functions.php` قالب چایلد (Child Theme) خود اضافه کنید.
۳. **نکته مهم:** در کد ارائه شده، عدد **83** (در نام فیلتر و متغیر `$form_id`) را به **ID فرم خودتان** تغییر دهید.
۴. آدرس `https://poian.ir/personal-information/` را با آدرس پنل کاربری سایت خود جایگزین کنید.

## 📌 پیش‌نیازها (Requirements)
* افزونه **Gravity Forms** نسخه ۲.۰ به بالا.
* درگاه پرداخت فعال و متصل به گراویتی فرم (Zarinpal، Mellat و ...).
* کاربر باید در سایت لاگین کرده باشد تا اطلاعات در متای او ذخیره شود.

## 📂 فیلدهای ذخیره شده در متای کاربر (User Meta)
| نام کلید در متای کاربر | مقدار (Value) | توضیحات |
| :--- | :--- | :--- |
| `moghadamati` | `true` | تاییدیه مرحله مقدماتی |
| `date_moghadamati` | `Y-m-d H:i:s` | تاریخ دقیق تایید پرداخت |
| `jashnvare8+` | `true` | فعال‌سازی دسترسی جشنواره پلاس |
| `3day_check_date_bargozari` | تاریخ + ۳ روز | موعد بررسی اول بارگذاری |
| `6day_check_date_bargozari` | تاریخ + ۶ روز | موعد بررسی دوم |
| `15day_check_date_bargozari` | تاریخ + ۱۵ روز | موعد بررسی سوم |
| `30day_check_date_bargozari` | تاریخ + ۳۰ روز | موعد بررسی نهایی |
