# آپدیت متادیتای کاربر پس از ویرایش ورودی گراویتی فرم

این قطعه کد به شما کمک می‌کند تا پس از ویرایش یک ورودی در Gravity Forms (فرم شماره ۱۲)، اطلاعاتی مثل کد ملی، تاریخ تولد شمسی و میلادی، و تصاویر را به صورت خودکار در Meta پروفایل کاربر آپدیت کنید.

### ویژگی‌ها:
* تبدیل تاریخ شمسی به میلادی
* ذخیره عکس پروفایل در متای کاربر
* آپدیت نام، نام خانوادگی و شماره‌های تماس

### نحوه استفاده:
کد را در فایل `functions.php` قالب چایلد (Child Theme) خود قرار دهید.
