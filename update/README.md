# به‌روزرسانی متادیتای کاربر با ویرایش ورودی گراویتی فرم (Gravity Forms Update User Meta)

این قطعه کد (Snippet) به شما کمک می‌کند تا هنگام استفاده از افزونه **Gravity Forms** در وردپرس، بلافاصله پس از اینکه یک ورودی (Entry) ویرایش یا به‌روزرسانی شد، اطلاعات آن را در متادیتای پروفایل کاربر (`user_meta`) ذخیره کنید.

## 🚀 ویژگی‌های کلیدی (Features)
* **اتصال خودکار:** همگام‌سازی فیلدهای فرم با فیلدهای شناسنامه کاربر.
* **تبدیل تاریخ:** دریافت تاریخ شمسی از فرم و تبدیل آن به میلادی برای ذخیره استاندارد در دیتابیس.
* **پشتیبانی از فایل:** ذخیره آدرس تصاویر آپلود شده (مثل لوگو یا عکس پرسنلی) در پروفایل کاربر.
* **مدیریت جنسیت:** تشخیص و ذخیره جنسیت بر اساس فیلدهای انتخابی (Checkbox/Radio).

## 🛠 نحوه استفاده (Installation)
۱. ابتدا کد موجود در فایل `update-user-meta.php` را کپی کنید.
۲. آن را به انتهای فایل `functions.php` قالب چایلد (Child Theme) خود اضافه کنید.
۳. **نکته مهم:** در خط اول کد، عدد `12` در `gform_after_update_entry_12` را به **ID فرم خودتان** تغییر دهید.
۴. شماره فیلدها (مثلاً `$entry['10']`) را مطابق با شماره فیلدهای فرم خودتان تنظیم کنید.

## 📌 پیش‌نیازها (Requirements)
* پنل وردپرس فارسی
* افزونه Gravity Forms
* نصب بودن افزونه‌های شمسی‌ساز (مثل Parsi Date) برای کارکرد تابع `jalali_to_gregorian`.
